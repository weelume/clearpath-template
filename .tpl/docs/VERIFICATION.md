# 实际验收

在本地 WSL Linux 文件系统使用固定 Node/pnpm 安装并构建，未使用远端构建。已执行 TypeScript、ESLint、双语详情和本地素材 SHA256 测试、生产构建；最终对应源码摘要与命令结果见 reports/verification.json。

浏览器检查覆盖19页×2语言×4视口=152组合，检查单一h1、页面错误与横向溢出；并触发菜单、FAQ、价格切换、团队弹窗、语言保留查询和锚点，以及表单必填/支持选项/演示反馈。三端12张真实截图覆盖首页、服务、期刊、预约。截图等待入场完成后采集，元数据采用解码尺寸，不能把配置视口当成图片尺寸。

字体和中文字号按约定调整，与参考站英文衬线字型存在有意差异；政策与表单说明以实际演示行为为准。关键运动类型已实现并进行运行状态检查，但原站所有动效的逐帧轨迹、精确时长和全部设备差异尚无逐像素一致性证据，不宣称逐帧完全一致。未验证真实业务发送、支付或医疗服务；模板未实现这些能力。素材商业再分发授权未确认。
